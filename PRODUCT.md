# Snapline · 晾图

A native Windows desktop adaptation of the screenshot clothesline concept in Alejandro Buján's Tendedero. People collect screenshots, see hanging thumbnails at the top edge, then copy, drag, open or annotate an image without navigating a folder.

Platform: Windows 10/11, Rust + Slint + Windows APIs. No browser runtime. Default language is simplified Chinese, with an English setting. Screenshots and imported files stay local. Folder monitoring copies source files into an owned cache.

Confirmed visual direction: retain the clothesline, thumbnails and gentle movement. Use independently authored name and icon. Expose settings and About from the native tray/menu. Image editing is local; video files open in the user's default app.
